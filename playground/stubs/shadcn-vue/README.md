# shadcn-vue stubs

Small components **shaped like shadcn-vue's** (new-york-v4: same exports, props,
events and `data-slot` markup as its Reka UI based `input`, `textarea`, `label`,
`checkbox`, `switch`, `radio-group` and `select`). They stand in for an app's
own `@/components/ui/*` so the playground and the tests can run the
`formo` registry item (`registry/shadcn-vue/formo`) without installing
shadcn-vue or Reka UI.
